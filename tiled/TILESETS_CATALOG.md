# Pokeemerald tilesets (colored for Tiled)

Source: `/Users/aaron/Downloads/pokeemerald/data/tilesets`

Each sheet is **8×8** tiles unless noted. Grayscale `tiles.png` in the repo is editor-only. **Colored** copies pick the correct palette **per 8×8 tile** using all `metatiles.bin` files (primary CHR 0–511, secondary CHR at 512+).

Paths below are under `Dashboard/tiled/tilesets/colored/`.

## Primary (3 sheets — used everywhere)

- **primary/building** — 128×256px (16×32 tiles @ 8px). Core indoor tiles: PCs, desks, lab equipment, walls, floors — best for Cursor/Claude HQ rooms.
- **primary/general** — 128×256px (16×32 tiles @ 8px). Shared outdoor/route tiles: grass, paths, ledges, trees, water edges — Main Space / routes.
- **primary/secret_base** — 128×256px (16×32 tiles @ 8px). Secret Base furniture and decorations.

## Tiled import

1. **New Tileset** → image from `colored/<name>/tiles.png`

2. Tile size **8×8**, margin 0.

3. A few tiles can still look wrong if the same 8×8 tile is reused with different palettes on different maps; rare for layout work.
